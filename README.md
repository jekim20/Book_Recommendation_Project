# 도서 추천 시스템 캡스톤

Amazon 도서 리뷰와 도서 정보를 이용해 추천 방식을 구현한 개인 캡스톤 프로젝트입니다. 현재 폴더에서 확인 가능한 학부 프로젝트 코드는 사용자 기반 협업 필터링과 SGD 행렬 분해입니다.

## 프로젝트 구성

- `capstone/user_based_cf.ipynb`: 사용자 평점 평균 중심화와 피어슨 유사도를 이용한 추천
- `capstone/matrix_factorization_lf.ipynb`: SGD 행렬 분해 추천
- `capstone/evaluate_holdout.py`: 2026년 정리 과정에서 추가한 단일 홀드아웃 평가
- `docs/reconstruction_notes.md`: 데이터 계보, 수정 내역, 평가 결과와 재현 한계

## 데이터

두 노트북과 평가 스크립트의 입력은 `capstone/books_review_2.csv`입니다. 리뷰 21,538건, 도서 제목 1,616개, 사용자 5,070명이 포함돼 있습니다. 중복 사용자-도서 리뷰를 평균 집계하면 19,767개 상호작용이 됩니다.

원본 데이터의 정확한 배포 버전과 라이선스는 현재 자료에서 확인되지 않아 CSV 파일은 저장소에 포함하지 않습니다. 프로젝트 자료에는 [Kaggle Amazon Books Reviews 데이터셋](https://www.kaggle.com/datasets/mohamedbakhet/amazon-books-reviews)이 출처로 기록돼 있습니다. 실행하려면 해당 입력을 별도로 확보해 `capstone/books_review_2.csv`에 둡니다. 데이터의 재배포 권한을 확인한 뒤 공개 여부를 결정하세요.

## 실행

Python 3.10 이상을 권장합니다. 저장소 루트에서 가상환경을 만들고 의존성을 설치합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r capstone/requirements.txt
```

VS Code에서 두 노트북 중 하나를 열고 `.venv` 커널을 선택해 실행합니다. 노트북은 `capstone/` 또는 저장소 루트에서 입력 파일을 찾습니다. 홀드아웃 평가는 다음 명령으로 실행할 수 있습니다.

```bash
python capstone/evaluate_holdout.py
```

## 확인된 결과와 한계

2026년 정리 시 두 노트북 전체를 실행했고, 평가 스크립트와 노트북의 홀드아웃 평가 결과를 확인했습니다. 단일 고정 분할(분할 시드 42)에서 SGD 행렬 분해의 RMSE/MAE는 1~5 범위 제한 후 1.9019/1.5873이었습니다. 전체 평균 기준선은 1.0753/0.8542, 사용자 평균 기준선은 1.1647/0.7902였습니다. 이 분할에서는 행렬 분해가 기준선보다 낮은 성능을 보였습니다.

이 홀드아웃 평가는 2026년에 새로 수행한 분석이며 2023년 결과가 아닙니다. 노트북에 저장돼 있던 낮은 RMSE는 학습 데이터에서 계산한 값입니다. 또한 발표자료에 언급된 아이템 기반, TF-IDF, 지식 기반 추천은 현재 보존된 실행 코드에서 확인되지 않았습니다. 코드와 데이터 전처리 이력이 모두 남아 있지 않아 2023년 실행을 완전히 재현했다고 주장하지 않습니다.
