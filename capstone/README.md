# 도서 추천 캡스톤 자료

저장소 공개용 개요는 상위 폴더의 [`README.md`](../README.md), 복원 근거와 상세 평가는 [`docs/reconstruction_notes.md`](../docs/reconstruction_notes.md)에 정리했습니다. 이 파일은 데이터 사전과 로컬 실행 참고용입니다.

## 로컬 실행

작업 폴더의 루트에서 가상환경을 만들고 의존성을 설치합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r capstone/requirements.txt
```

Python 3.10 이상을 사용합니다. VS Code에서 `user_based_cf.ipynb` 또는 `matrix_factorization_lf.ipynb`를 열고 커널로 `.venv`를 선택합니다. 노트북은 현재 작업 디렉터리가 작업 폴더 루트이거나 `capstone/`일 때 `books_review_2.csv`를 찾습니다. 원본 데이터 전체가 필요하지는 않지만, 이 파일은 노트북과 평가 스크립트가 실행되는 위치에서 접근 가능해야 합니다.

재현 가능한 홀드아웃 평가는 표준 라이브러리만 사용합니다.

```bash
python capstone/evaluate_holdout.py
```

행렬 분해 노트북 끝에도 같은 평가를 실행하는 셀이 있습니다.

## 재현 범위

이 자료는 2023년 프로젝트를 현재 확보된 파일과 현재 로컬 실행 방식으로 정리한 것입니다. 과거 Colab의 Python·패키지 버전과 데이터 생성 전체 코드가 보존돼 있지 않아, 당시 숫자와 결과를 비트 단위로 재현했다고 주장할 수 없습니다. 노트북에 저장돼 있던 출력은 저장 당시 실행 결과일 수 있습니다.

`evaluate_holdout.py`의 평가는 포트폴리오 정리를 위해 새로 추가한 실험입니다. 원래 노트북과 같은 데이터 집계, 요인 수, 반복 횟수, 학습률, 정규화 및 SGD 업데이트 순서를 사용하지만, Python 표준 라이브러리의 난수 초기화를 사용하므로 NumPy 난수 초기값과 같지 않습니다. 이 평가는 과거 결과의 복원이 아니라 현재 데이터에 대한 새 평가입니다.

정확한 재실행 기록을 위해 노트북 실행 시 Python, NumPy, pandas 버전과 입력 CSV의 체크섬을 함께 보관하는 것을 권합니다. `requirements.txt`는 설치 편의를 위한 목록이며, 2023년 환경을 고정한 잠금 파일은 아닙니다.

## 입력 데이터와 데이터 사전

모델 입력은 `books_review_2.csv`입니다. 행은 리뷰 단위이며, 협업 필터링 노트북은 `user_num`과 `Title`별 평점을 피벗 테이블로 집계합니다. 같은 사용자가 같은 책에 남긴 복수 리뷰는 평균 평점 한 건으로 바뀝니다. 데이터 파일은 공개 저장소에서 제외되므로 로컬에 별도로 준비해야 합니다.

| 컬럼 | 의미 | 사용 시 참고 |
|---|---|---|
| `Title` | 책 제목 | 도서 정보와 리뷰를 연결하고 추천 결과를 표시하는 키 |
| `description` | 책 설명 | 콘텐츠 기반 추천에 사용할 수 있는 텍스트 |
| `authors` | 저자 | 도서 메타데이터 |
| `publisher` | 출판사 | 도서 메타데이터 |
| `categories` | 장르·분류 | 도서 메타데이터 |
| `year` | 출판 연도 | 정수 또는 문자열로 다뤄질 수 있음 |
| `Id` | 도서 식별자 | 원천 데이터의 도서 ID/ISBN 값 |
| `Price` | 가격 | 값이 비어 있거나 문자열일 수 있음 |
| `review/helpfulness` | 리뷰 유용성 비율 | 원천 리뷰의 도움됨 투표 비율 |
| `review/score` | 평점 | 1~5점 |
| `review/time` | 리뷰 날짜 | `YYYY-MM-DD` 형식 |
| `review/summary` | 리뷰 제목 | 리뷰 텍스트 |
| `review/text` | 리뷰 본문 | 자연어 분석에 사용할 수 있는 텍스트 |
| `user_num` | 사용자 번호 | 원천 `User_id`를 숫자로 대응시킨 값으로 기록돼 있음 |

## 데이터 계보와 확인된 규모

- 원본 평점 파일은 3,000,000개 리뷰 행과 10개 컬럼을 가집니다. 작업 폴더의 `Books_rating-001.csv`와 `Books_rating-002.csv`는 내용이 완전히 같아 한 번만 세어야 합니다.
- `데이터셋/Books_rating_1.csv`는 414,548개 행, 9개 컬럼입니다.
- `데이터셋/books_data_1.csv`는 40,635개 행, 7개 컬럼입니다.
- `books_review_2.csv`는 21,538개 리뷰 행, 14개 컬럼, 5,070개 사용자 번호, 1,616개 제목으로 구성됩니다. 모든 행의 리뷰 필드는 전처리 평점 파일과 일치하고, 모든 제목은 전처리 도서 정보에 있습니다.
- 리뷰 행에서 사용자별 최소 개수는 1이고 책별 최소 개수는 5입니다. 사용자 5,070명 중 1,503명은 리뷰 행이 3개 미만입니다. `pivot_table`처럼 사용자-책을 평균 집계하면 1,951명은 서로 다른 책을 3권 미만으로 평가했습니다. 발표자료에 적힌 사용자 최소 리뷰 조건이 현재 파일에 반영되지 않았으므로, 최종 필터 기준은 확인되지 않았습니다.
- `books_review_3.csv`는 빈 이름의 열 39개가 있고 평점 열이 밀린 행이 있어 입력으로 사용하지 않습니다.

## 홀드아웃 평가

평가 스크립트는 노트북의 `pivot_table` 동작과 맞추기 위해 먼저 사용자-책 중복 리뷰를 평균으로 집계합니다. 이후 책마다 적어도 하나의 학습 상호작용이 남도록 하면서, 두 권 이상을 평가한 사용자마다 한 건을 검증 데이터로 남기는 leave-one-out 분할을 합니다. 단일 상호작용 사용자 726명은 학습 데이터에만 남습니다. 분할 시드는 42, 요인 초기화 시드는 1입니다. 계산은 표준 라이브러리로 재현하므로 NumPy 난수 생성기와 초기 숫자 배열 자체는 원래 노트북과 다릅니다. 평가 코드는 동일한 사용자-책 행렬, 요인 수, 반복 횟수, 학습률, 정규화 계수와 업데이트 순서를 사용합니다.

| 항목 | 값 |
|---|---:|
| 원본 리뷰 행 | 21,538 |
| 사용자-책 중복쌍 | 1,333 |
| 집계 후 상호작용 | 19,767 |
| 학습 / 검증 | 15,423 / 4,344 |
| 검증 사용자 / 책 | 4,344 / 1,351 |

SGD 행렬 분해는 노트북과 같은 설정(잠재 요인 50, 200 epoch, 학습률 0.01, 정규화 0.01)으로 평가했습니다. 결과는 단일 고정 분할 기준입니다.

| 예측 방식 | RMSE | MAE |
|---|---:|---:|
| 전체 학습 평점 평균 | 1.0753 | 0.8542 |
| 사용자별 학습 평점 평균 | 1.1647 | 0.7902 |
| SGD 행렬 분해, 원점수 | 1.9509 | 1.6157 |
| SGD 행렬 분해, 1~5점 범위로 제한 | 1.9019 | 1.5873 |

이 분할에서 행렬 분해는 전체 평균과 사용자 평균 기준선보다 좋지 않았습니다. 원점수의 범위는 -1.431~5.456이었고, 제한한 점수로도 기준선을 넘지 못했습니다. 이 평가는 한 번의 분할 결과이며, 여러 시드 반복이나 사용자 기반 협업 필터링과의 동일 조건 비교는 아직 하지 않았습니다. 저장된 노트북의 기존 RMSE 로그는 학습 데이터에 대한 값이므로 이 검증 결과와 구분합니다.

## 노트북에서 확인되는 코드 범위

- `user_based_cf.ipynb`: 사용자 평점 평균 중심화, 피어슨 유사도, 이웃 기반 미평가 도서 추천. 작업용 사본은 가중 편차를 유사도 합으로 나누고 예측값을 1~5 범위로 제한하도록 수정했습니다. 2026-11-10 전체 재실행을 완료했고, 출력 점수가 1~5 범위인지 확인했습니다.
- `matrix_factorization_lf.ipynb`: SGD 행렬 분해와 사용자별 미평가 도서 추천.
- 아이템 기반 CF, TruncatedSVD, TF-IDF, 키워드 분석, 지식 기반 추천은 발표자료에 설명이 있으나 현재 작업 폴더의 노트북에는 대응 코드가 없습니다.

2026-11-10 두 작업용 노트북을 전체 실행해 오류 없이 완료했습니다. 노트북에 저장된 학습 RMSE와 홀드아웃 검증 결과는 다른 값이며, 상세 결과와 재현 한계는 상위 폴더의 복원 노트를 참고하세요.
