### 기존 노트북의 최소 수정

- 두 노트북에서 Google Colab 드라이브 마운트와 `/content/drive/...` 경로를 제거하고, 프로젝트 루트 또는 `capstone/`에서 `books_review_2.csv`를 찾도록 바꿨습니다.
- 사용자 기반 노트북에서 유사도 가중 평점 편차를 이웃 수로 나누던 부분을 유사도 가중치 합으로 나누도록 고쳤습니다. 예측 평점은 데이터 평점 범위인 1~5로 제한합니다. 이 변경은 추천 결과에 영향을 주므로 이전 셀 출력은 지웠고, 수정 전 노트북은 `originals/`에 보존했습니다.
- 행렬 분해 노트북의 RMSE 계산에서 scikit-learn 호출을 NumPy 연산으로 바꿨습니다. 입력 배열에 대한 RMSE 정의는 같습니다.

- 현재 폴더에는 사용자 기반 협업 필터링과 SGD 행렬 분해 노트북만 있습니다.
- 아이템 기반 CF, TF-IDF, 지식 기반 추천, TruncatedSVD 코드는 현지 노트북에서 확인되지 않았습니다. 발표·보고서에 설명만 남아 있습니다.
- 2026-11-10 확인: 두 작업용 노트북을 현재 로컬 환경에서 전체 실행했고 오류 없이 완료했습니다. 사용자 기반 추천 출력은 수정된 계산으로 1~5 범위에 들어왔습니다. 행렬 분해 노트북의 홀드아웃 셀은 `evaluate_holdout.py`와 같은 지표를 출력했습니다.
- 공개 전 점검: 사용자 기반 노트북 경고 출력에 포함된 개인 임시 커널 경로만 노트북 셀 표기로 바꿨습니다. 경고 내용과 계산 결과는 유지했습니다.
- 공개 전 점검: 두 노트북에서 원본 데이터·사용자-도서 행렬 미리보기 출력만 제거했습니다. 실행 코드는 그대로 두고 추천 예시와 학습·홀드아웃 결과는 보존했습니다.
