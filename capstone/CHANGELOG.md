# 변경 기록

## 원본과 로컬 실행

- 원본 ZIP에서 꺼낸 두 노트북은 `originals/`에 보관했다.
- Google Colab 드라이브 마운트와 절대 경로를 제거하고, 저장소 루트 또는 `capstone/`에서 입력 CSV를 찾도록 바꿨다.
- 사용자 기반 협업 필터링에서 가중 평점 편차를 유사도 합으로 나누도록 수정하고, 예측 점수를 1~5점으로 제한했다. 원래 출력에 있던 5점 초과 예측을 바로잡기 위한 수정이다.
- 행렬 분해 노트북의 RMSE 계산에서 scikit-learn 호출을 NumPy 연산으로 바꿨다.

## 2026년 재실행과 평가

- 두 노트북을 로컬 환경에서 처음부터 실행했다. 수정한 사용자 기반 추천 결과와 행렬 분해 추천 결과를 확인했다.
- 홀드아웃 평가 스크립트 `evaluate_holdout.py`를 추가하고, 행렬 분해 노트북에도 평가 셀을 넣었다. 평가와 기준선 비교 결과는 [복원 기록](../docs/reconstruction_notes.md)에 정리했다.
- 공개본에서 입력 데이터와 사용자-도서 행렬 미리보기 출력을 지우고, 경고 출력에 남은 개인 임시 경로를 노트북 셀 이름으로 바꿨다. 계산 코드와 추천 결과는 유지했다.

## 공개 저장소 정리

- 실행 방법과 데이터 컬럼 설명을 `README.md`에 추가했다.
- 데이터 출처 버전과 재배포 권한이 확인되지 않아 CSV와 압축 파일을 공개 대상에서 제외했다. 개인 발표·진행 자료와 원본 노트북 사본도 로컬에만 둔다.
- 루트 README에는 프로젝트 개요와 방법을, 이 폴더의 README에는 코드·입력 데이터·실행 절차를 정리했다.
