# 프로젝트 복원 기록

2023년 캡스톤 프로젝트 자료를 로컬에서 다시 살펴보며 데이터 파일의 관계와 노트북의 실행 과정을 정리했다. 학부 당시 코드와 2026년에 고친 부분, 새로 계산한 평가 결과를 구분해 적는다.

## 데이터 파일

| 단계 | 파일 | 확인 내용 |
|---|---|---|
| 원본 리뷰 | `Books_rating-001.csv`, `Books_rating-002.csv` | 각각 3,000,000행, 10개 열. 두 파일은 바이트 단위로 동일하다. |
| 전처리 리뷰 | `capstone/데이터셋/Books_rating_1.csv` | 414,548행, 9개 열 |
| 전처리 도서 정보 | `capstone/데이터셋/books_data_1.csv` | 40,635행, 7개 열 |
| 노트북 입력 | `capstone/books_review_2.csv` | 21,538행, 14개 열, 사용자 5,070명, 제목 1,616개 |

`books_review_2.csv`의 리뷰 제목·평점·날짜·요약·본문은 전처리 리뷰 파일의 해당 값과 일치했다. 이 파일의 모든 도서 제목도 전처리 도서 정보에서 찾을 수 있었다. 두 노트북은 `books_review_2.csv`를 읽고, `user_num`과 `Title`별 평점을 평균으로 집계한다. 그 결과 리뷰 행 21,538개가 사용자-책 조합 19,767개로 줄며, 1,333개 조합에 중복 리뷰가 있다.

발표자료에는 사용자별 최소 리뷰 수 조건이 적혀 있지만, 현재 입력에는 리뷰가 3건 미만인 사용자가 5,070명 중 1,503명 있다. 사용자-책 조합을 평균으로 합친 뒤에도 1,951명이 서로 다른 책을 3권 미만 평가했고, 726명은 한 권만 평가했다. 최소 리뷰 조건을 적용한 시점과 기준은 남아 있는 파일만으로 확인할 수 없어 입력을 임의로 다시 필터링하지 않았다. 책별 리뷰 수의 최솟값은 5건이다.

`capstone/books_review_3.csv`는 빈 열 이름이 39개 있고 일부 행에서 평점 열이 밀려 있어 입력으로 쓰지 않았다. `capstone/books_new_1.csv`는 24행 중 3행이 비어 있고, 나머지 대부분의 `user_num`이 `9999`라 두 노트북의 입력으로 보지 않았다.

원본 리뷰 파일 두 개는 내용이 같아 중복 계산 대상이 아니다. 원본에서 전처리 파일과 최종 입력을 만든 전체 절차, Kaggle 데이터의 정확한 버전과 라이선스는 남아 있지 않다. 그래서 CSV와 압축 파일은 저장소에서 제외했다.

## 노트북과 수정 내용

현재 정리한 노트북은 사용자 기반 협업 필터링과 SGD 행렬 분해다. 과거 발표자료에는 아이템 기반 CF, TruncatedSVD, TF-IDF, 리뷰 키워드 분석, 지식 기반 추천도 등장하지만, 이 저장소의 두 노트북에는 해당 실행 코드가 없다.

### 사용자 기반 협업 필터링

사용자별 평균을 빼 평점을 중심화하고, 피어슨 상관계수로 비슷한 사용자를 찾은 뒤 그들의 평가를 이용해 미평가 도서 점수를 계산한다. 원래 예측식은 이웃의 가중 평점 편차를 이웃 수로 나눴다. 2026년 정리에서 이를 유사도 합으로 나누도록 고치고 예측값을 1~5점으로 제한했다. 원본 노트북 출력에는 5점을 넘는 예측이 있어, 수정한 계산의 결과와 구분했다.

### SGD 행렬 분해

노트북은 사용자-도서 평점 행렬을 잠재 요인 50개로 분해하고, SGD로 200회 갱신한다. 학습률은 0.01, 정규화 계수는 0.01이다. RMSE 계산에서 scikit-learn 의존성을 NumPy 연산으로 바꿨다. 이 계산은 관측된 학습 평점에서 이뤄지므로 노트북의 낮은 RMSE는 학습 적합도를 나타낸다.

원본 ZIP에서 꺼낸 노트북 사본은 `capstone/originals/`에 보관한다. 작업용 노트북에서는 Colab 드라이브 경로를 로컬 상대 경로로 바꾸고, 수정한 셀과 추가한 평가 셀을 실행했다. 공개본에서는 원본 리뷰·사용자-도서 행렬 미리보기 출력과 개인 임시 경로가 드러나는 경고 경로를 정리했다. 실행 코드와 추천 결과는 유지했다.

## 2026년 홀드아웃 평가

`evaluate_holdout.py`와 행렬 분해 노트북 끝에 추가한 셀에서 새 평가를 수행했다. 같은 사용자가 같은 책에 남긴 평점을 먼저 평균으로 합친 뒤, 두 권 이상 평가한 사용자마다 한 건을 검증용으로 남겼다. 각 검증 도서는 학습 데이터에도 남도록 분할했다. 한 권만 평가한 사용자는 학습 데이터에만 포함했다.

분할 시드는 42, 행렬 요인 초기화 시드는 1이다. 행렬 분해 설정은 요인 50개, 200 epoch, 학습률 0.01, 정규화 0.01이다. 학습 15,423개, 검증 4,344개 상호작용으로 나뉘었고, 검증에는 사용자 4,344명과 책 1,351개가 포함됐다.

| 예측 방식 | RMSE | MAE |
|---|---:|---:|
| 전체 학습 평점 평균 | 1.0753 | 0.8542 |
| 사용자별 학습 평점 평균 | 1.1647 | 0.7902 |
| 행렬 분해 원점수 | 1.9509 | 1.6157 |
| 행렬 분해 점수를 1~5로 제한 | 1.9019 | 1.5873 |

이 단일 분할에서는 행렬 분해가 평균 기준선보다 나은 결과를 내지 못했다. 원점수 예측 범위는 -1.431~5.456이었다. 여러 분할의 평균이나 사용자 기반 추천과의 동일 조건 비교는 아직 계산하지 않았다.

`capstone/evaluate_holdout.py`는 Python 표준 라이브러리 난수 생성기를 쓴다. 시드와 SGD 설정은 기록했지만 2023년 노트북의 NumPy 난수 초기값과는 다르다. 따라서 이 결과는 학부 당시 결과를 재생성한 것이 아니라, 현재 확보한 데이터에 대해 2026년에 새로 계산한 값이다.

## 실행 환경과 남은 기록

2026년 11월 10일 Python 3.11.15, NumPy 2.4.6, pandas 3.1.1, ipykernel 7.4.0 환경에서 두 노트북을 처음부터 실행했다. 사용자 기반 추천 결과는 1~5점 범위에 들었고, 행렬 분해 노트북의 홀드아웃 결과는 `evaluate_holdout.py` 출력과 일치했다. 학습 로그에서 마지막으로 출력된 RMSE는 190번째 반복의 약 0.02644다.

2023년 Colab의 Python·패키지 버전과 전체 데이터 생성 코드는 보존돼 있지 않다. `requirements.txt`도 버전을 고정하지 않은 설치 목록이다. 또 기존 발표자료에 나온 다른 추천 방법의 실행 코드와 사용자 필터 적용 기록을 찾지 못했다. 현재 보유한 자료만으로는 당시의 전체 실험 과정을 그대로 복원할 수 없다.
